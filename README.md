# Superstore Sales Analysis

## Project Overview
This project analyzes retail sales data to identify top-performing products, regions, and sales trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Key Insights
- Identified top 10 products contributing highest revenue
- Cleaned missing and inconsistent data
- Visualized trends for business insights

## Dataset
Superstore dataset in CSV format

## Conclusion
Helps businesses make data-driven decisions.
